## Features & Assignment Requirements Met

*   **Google OAuth2 Integration:** Implemented the Google Identity Services token client to securely authenticate users and fetch spreadsheet data.
*   **Dynamic Data Parsing:** Retrieves CSV/Sheet data and maps it to custom HTML tiles, accurately reflecting the requested "Image B" layout (Country, Age, Photo, Name, Interest).
*   **Algorithmic Color Coding:** Tiles are dynamically color-coded based on numerical net worth values (Red < $100K, Orange > $100K, Green > $200K).

*   **Table:** Configured to a strict **20x10** grid layout.
*   **Sphere:** Distributed evenly across a 3D globe.
*   **Helix:** Configured to display a **Double Helix** pattern instead of the default single strand.
*   **Grid:** Configured to a **5x4x10** volumetric block.
*   **Robust Error Handling:** Includes `try/catch` blocks around asynchronous network requests, handling potential API failures or 404s gracefully with user-facing UI updates.
